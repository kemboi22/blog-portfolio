# Using Inertia.js with Laravel and Vue.js

## Create A Laravel Project

To create a new Laravel project, you need to have Composer installed on your system. If you don't have Composer installed, you can download it from the [official website](https://getcomposer.org/download/).

To create a new Laravel project, run the following command in your terminal:

```bash
composer create-project laravel/laravel test
```
## Install Inertia.js using Breeze

Inertia.js is a library that allows you to create single-page applications using server-side routing and controllers. It's a great way to build modern web applications without having to write a lot of JavaScript code.
Install Inertia Breese using the following command:

```bash
composer require laravel/breeze --dev
```
Next, run the following command to install Inertia.js and Vue.js:

```bash
php artisan breeze:install
```
This command will install Inertia.js and Vue.js in your Laravel project. It will also create the necessary routes, controllers, and views for your application.

This will install inertia.js and vue.js in your Laravel project.

## Running the Application

To run the application, use the following command:

```shell
php artisan serve
```
```shell
npm run dev
```
This will start a development server on `http://localhost:8000`. You can access your application by visiting this URL in your browser.
